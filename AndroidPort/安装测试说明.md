> 本版本是一次彻底重构:游戏不再使用程序生成的占位素材,
> **画面、地图、单位全部来自原版《星际争霸:母巢之战》1.16.1 的真实游戏数据**,
> 由自研的 MPQ 逆向工具链直接提取。
> v2.2 修复了 v2.1 的回归(命令图标、爆炸特效、虫族语音、架塔闪退)。
> v2.3 把**原版游戏内界面(console)移植到手机端**:线框头像、官方单位名、
> 3×3 命令卡、金属面板,并针对手机屏幕做了适配。
> v2.4 修正了**全局调色板红蓝通道反了**的底层 Bug(矿物/火光/爆炸/地面
> 颜色全部恢复原版样貌),并补齐五批反馈、地图与战斗表现、UI 功能。
> v2.5 修掉了单位/建筑发透的阴影 alpha 回归,命令卡加大并加中文名与造价,
> 信息面板半透明化;批次六补上巡逻 / 修理 / 攻击移动、编队与存档读档,
> 并改用 release 签名 + 素材精简(APK 22.3 MB → 5.9 MB)。
> v2.6 去掉了顶栏与底部控制台的两条大黑块(改为淡衬底,战场从中间透出),

> v2.7 三线推进:UI(原版结算面板 + 设置页 + 小地图下令)、剧情(数据驱动的
> 任务引擎 + 5 关人族迷你战役)、战斗(学院 / 工程湾 / 护甲 / 兴奋剂 / 升级)。

## 一、拿到什么

| 文件 | 说明 |

## 二、安装方法

把 `星际争霸RTS-v2.7.apk` 传到手机,任选一种:

1. **手机上直接装**:文件管理器点开 APK,允许"安装未知来源应用"。
2. **数据线 + adb**:`adb install -r 星际争霸RTS-v2.7.apk`
3. **微信/QQ 传输**:发到手机后点开安装。

> release 自签名包,安装时提示"未知开发者"属正常现象。

## 三、这一版是什么

### 用的是真素材
- **真实地图 9 张**:血浴、猎手、瓶颈、拳王、暗黑水晶、三国、小分界、风暴、火山
  ——全部从原版 `.scm` 地图文件解析而来:地形图块、水晶矿、气矿、出生点
  都是暴雪设计师摆的原样。
- **真实单位精灵**:SCV、机枪兵、喷火兵、雷车、攻城坦克、小狗、刺蛇、飞龙、
  指挥中心、兵营、重工厂、补给站、导弹塔……16 个朝向 + 行走/开火动画,
  蓝色(我方)/红色(敌方)队伍配色,从原版 GRP 调色板重映射生成。
- **真实地形渲染**:按原版图块集三表(CV5/VX4/VR4)+ 调色板(WPE)逐像素合成,
  可走性来自 VF4 旗标(经出生点连通性验证)。
- **真实爆炸与死亡动画**:`unit\thingy\tBangS/L/X` 三档爆炸序列,
  以及机枪兵/小狗/刺蛇的死亡动画(取自 GRP 尾帧)。
- **原版标题画面**:640×480 的《星际争霸》标题图(PCX 解码)。
- **命令卡图标**:按 `units.dat` 单位编号取自原版 `cmdicons.grp`,
  与单位一一对应。
- **原版 console 界面(v2.3 新增)**:
  - **线框头像 228 张**:原版 `wirefram.grp`,按 `units.dat` 编号索引,
    选中任何单位时在左下角显示它 1998 年的线框图;
  - **官方单位名**:取自 `rez\stat_txt.tbl`,如 "Terran Marine"、
    "Terran Siege Tank",与中文名并列显示;
  - **3×3 命令卡**:原版网格布局,凹槽质感,真图标;
  - **金属面板 + 三色 HP 条**:原版绿/黄/红血量规则。

### 玩法(经典 RTS)
- **经济**:SCV 自动/手动采水晶矿,送回指挥中心入账;在气矿上建炼油厂后,
  部分 SCV 自动转采高能瓦斯(坦克/刺蛇/飞龙需要气)。
- **坦克架塔**:选中攻城坦克 → "架塔"按钮,切换攻城模式(射程/伤害大增、不能移动)。
- **原版语音 39 条**:SCV/机枪兵/喷火兵/雷车/坦克/小狗/刺蛇/飞龙/雄蜂
  各带 就绪/询问/确认/阵亡 四种台词,另有爆炸/建造/错误/点击音效。
- **生产**:指挥中心造 SCV,兵营出机枪兵/喷火兵,重工厂出雷车/坦克(有生产队列)。
- **建造**:选中 SCV → 建造按钮 → 地图上放置。补给站提供人口。
- **战争迷雾**:未探索区域全黑,已探索半暗,敌方单位只在视野内显示。
- **敌方 AI(虫族)**:持续生产部队,随时间增强,定期组织进攻波次;
  基地有地刺防守。
- **胜负**:拆光敌方建筑获胜;我方全灭失败(点击任意处返回主菜单)。

## 四之二、战役(人族迷你战役,5 关)

主菜单顶部有「战役 / 遭遇战」两个标签页。战役按顺序解锁:通过第 N 关
解锁第 N+1 关,进度存在应用私有目录,重进保留。

| 关 | 地图 | 目标 | 教学点 |
|---|---|---|---|
| 1 立足 | 小分界 | 守住指挥中心 8 分钟 | 基础运营、编队 |
| 2 拔点 | 瓶颈 | 歼灭虫族前哨 | 攻击移动、坦克架塔 |
| 3 驰援 | 拳王 | 10 分钟内保住东线友军兵营 | 机动、巡逻 |
| 4 夺取矿区 | 暗黑水晶 | 摧毁中央据点并守住 | 扩张、双目标 |
| 5 毕业考 | 猎手 | 全图歼灭(敌方波次最强) | 综合 |

每关开始有简报(点屏幕逐条翻),战斗左上角显示目标 ✓/✗,事件会弹字幕。
结算面板显示目标达成数、击杀/损失/采集/耗时,并给 S/A/B/C 评价
(S = 无损失,含可选目标全达成)。

## 五、已知限制

- **原版 BGM 不存在于本重打包**:用"从扇区偏移表反解文件密钥"的办法
  (`tools/probe_music5.py`)逐块识别了全部 >=300KB 的加密块,只有音效 WAV、
  DOS 安装器和全零空洞,没有任何音乐轨。所以游戏内「音乐」开关按设计
  静默 no-op(显示「(无曲目)」);往 `assets/music/` 放任意 `.ogg/.wav`
  即自动循环播放,无需改代码。
- **原版游戏内 HUD 的金属底图(`glue\Console\*.pcx`)不在这份盗版包里**,
  所以面板质感是用代码复刻的;头像、命令图标、单位名这些内容资产是真的。
- 包里也没有位图字体(`tFont.pcx` 只是一条 40×1 的渐变色带),
  文字仍用 Android 系统字体绘制。
- 个别地图图块因老盗版包数据缺损(每文件约几十字节)存在极少量像素级瑕疵,
  已通过"缺口感知"读取把影响降到最低。
- 敌方 AI 难度平衡偏娱乐向,不做天梯级强度。
- 音量为 0/25/50/75/100% 五档,未做连续滑条。

## 六、技术亮点(为什么这很难)

原版 1.16.1 的 `StarDat.mpq / BrooDat.mpq` 是 1998 年的封闭格式,且本机这份
为盗版重打包(每文件扇区尾部丢 1~7 字节)。本工程全部自主逆向:

1. MPQ 容器(哈希表/块表/扇区加密)与文件密钥规则;
2. PKWARE DCL implode 解压;
3. **MPQ 自适应(FGK)Huffman 解码器** + ADPCM(ADI)单声道解码器;
4. 小文件扇区偏移表探测(原版格式的坑);
5. **缺口感知读取**(GapReader):把重打包丢的字节当"已知位置的洞",
   结构化数据按原始坐标读取,仅损失洞内的几个像素;
6. GRP 精灵格式(8 字节帧头 + 行偏移表 + 3 类 RLE 操作码);
7. 地形三表链路 MTXM → CV5 → VX4 → VR4 + WPE 调色板;
8. **用游戏自身的数据表定位素材**:`arr/images.tbl`(719 条 GRP 路径)、
   `arr/units.dat`(单位编号)与 `rez/stat_txt.tbl`(官方名称)
   替代人工猜测路径与索引——线框头像、命令图标、单位名三者
   全部按同一个单位 ID 对齐,不需要任何人工映射表;
9. PCX 标题图解码(头部包围盒 + 调色板索引);
10. 桌面 JVM 验证台:同一份核心模拟代码在 PC 上渲染 PNG 逐帧验收,
    含一个针对"架塔闪退"的最小复现用例;
11. **HUD 布局断言**:`HudPreview.java` 在三种手机分辨率下渲染 console,
    并断言信息区与命令卡不重叠、卡片不出屏。

详细过程见 `进展报告.md`。
