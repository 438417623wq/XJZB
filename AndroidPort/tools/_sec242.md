## 八之四十二、v2.41:对局 HUD 独立部件化(撤掉上下两条透明带,战场全屏)

v2.39 之后玩家反馈:屏幕**上下各有一大块"透明的板块窗口"**,要求去掉,
信息显示**各自独立成 UI**——时间是单独 UI、九宫格是单独 UI、小地图是
单独 UI。查明根因后本期把 v2.6 以来"顶栏带 + 底台带"这条**布局骨架**
整个拆掉:v2.23 只是把带涂透明,带还占着布局、相机与手势;v2.41
**去掉的是带本身**。方案见 `v2.41方案-对局HUD独立部件化.md`。
`GameDesktop` 新增 `[v241]` 段(6 组源级断言),并同步重写了
`[layout]`/`[v219]`/`[v220]`/`[v221]` 的几何镜像(带模型退役),
全量 **109 项 PASS**。

### 玩家看到的两块"透明窗口"是什么

v2.23 删掉压暗层之后,顶栏(40dp)和底台(约 150dp+)各剩一条
"无背景、只有一条 1px 分隔线"的常驻带。它们被读成"窗口"的三个原因:
① 分隔线像窗框;② 相机画面锚定在两带之间的 playfield,带里透出的
地形**看得见摸不着**(点它不出兵、框选无效);③ 手势层把两带整块
划成 HUD 死区(`inHud()` 按 y 判带、拖动被 `consoleH()` 挡住)。

### 目标形态(设计基调一句话)

**屏幕 = 全屏战场 + 六个独立不透明部件;部件之间没有任何带、线、垫层,
部件之外的每一像素都是活战场(可点兵、可拖动、可框选)。**

| 部件 | 位置(默认) | 来源 |
|---|---|---|
| 暂停芯片 | 左上 | 已有,矩形改由 HudLayout 生成 |
| 资源芯片 | 暂停右侧(晶体/瓦斯/人口,人口超载整块描红边) | **新增** |
| 时间芯片 | 顶中(mm:ss) | **新增** |
| 战况芯片 | 右上(我方/敌方;与时间芯片重叠时自动隐藏) | **新增** |
| 小地图 | 左下(150dp 槽) | 已有,脱离底台 |
| 信息面板 + 九宫格 | 中 / 右下 | 已有,脱离底台 |

### 三批落地

- **批次A 拆带**:`HudLayout` 删除 `consoleTop`/`consoleHeight` 输出,
  `centerY = H/2`(相机钳制天然全屏,地图南缘可拖到屏底);
  `inHud()` 重写为"点在任一部件矩形内",部件缝隙全部落到地图;
  拖动/框选的 `consoleH()` 死区改为部件判定(手指滑进部件暂停、
  滑出继续);边缘滚动改为全屏四沿。
- **批次B 部件化绘制**:`drawTopBar` 拆成暂停/资源/时间/战况四块
  不透明金属芯片(文字自适应缩排);`drawConsolePanel` 改名
  `drawBottomWidgets`,两条 hairline 删除;小地图/信息/九宫格
  绘制零改动(它们已是不透明面板)。
- **批次C 编辑器扩展 + 杂项重锚**:布局编辑器 3→5 面板(时间/资源
  可拖可调 S/M/L);自定义布局 spec **9→15 floats**,旧 9-float 存档
  自动迁移(新芯片落默认位);toast、任务消息、回放横幅、任务目标
  全部改锚到部件矩形,不再引用带高。

### `[v241]` 断言(源级,6 组)

1. **带退役**:HudLayout/GameView 中不再存在 `consoleTop`、带高函数、
   `TOPBAR_RULE` 分隔线、`y < topBarH()` 手势豁免;
2. **六部件**:pause/clock/res/tally 矩形由布局生成,`inHud()` 逐矩形
   判定,绘制入口只有 `drawTopChips`/`drawBottomWidgets` 两处;
3. **相机全屏**:`centerY = H/2`(镜像断言 `[layout]` 同步改为全屏包络);
4. **手势**:拖动守卫与边缘滚动不再按带计算;
5. **重锚**:toast/任务消息(底排最高部件上沿)、回放横幅(时间芯片
   下沿)、任务目标(顶排芯片下沿);
6. **spec15**:15-float 规格常量 + 旧档迁移分支在场;
   `[layout]`/`[v219]`/`[v220]`/`[v221]` 镜像同步重写后全绿。
