## 八之三十、v2.30:WiFi 本地对战(锁步核心)

路线图最后一格「WiFi 本地对战 + 观战」的**可无头验证的那一半**落地:
`core/Lockstep.java` + `Game` 接入 + `[v230]` 段 1 项(9 个子断言),
全量 **99 项 PASS**。

### 为什么这期几乎没有新机制

v2.19/v2.20 已经把难的部分做完了:固定 30Hz 定步长、带 tick 与
实体下标的文本指令流、`stateHash` 每秒采样、RNG 固定种子——
`[v220]` 的 replay determinism 断言**已经证明**"同一指令流跑两次
结果全等"。锁步唯一要补的是**让两台机器在同一个 tick 拿到同一批
命令、并按同一顺序执行**。这一期就只写这一件事。

### 实现

- `Lockstep`:一个回合 = 一个 tick(30Hz)。每个玩家每回合必须**上报**
  (没有命令也要发心跳,否则对面永远等);全员上报后 `release()`
  按 **玩家 id 升序** 排出规范顺序并 `turn++`。规范顺序是两台机器
  唯一必须一致的东西,也是这套东西唯一容易写错的一行;
- 命令**复用回放格式**(`<verb> <idx,idx,…> <args>`),不发明新语法。
  于是**一场对战序列化出来就是一份合法回放**——网络层、回放层、
  断言层共用同一条指令通道,没有"联机专用的隐藏状态";
- `Game.lockstep` / `lockstepPlayer`:有 session 时 `recordCommand` /
  `recordOrder` 改为**先喂锁步**(而不是写本地 `replayLog`),
  `update()` 开头未 `ready()` 就**直接 return**(这一帧不推进),
  ready 则把 `release()` 出来的命令逐条 `applyCommand`——**和回放
  走的是同一个函数**;
- 本地玩家自己的命令也走同一条路,所以**本地命令在下一回合生效**。
  这不是延迟 bug,是锁步的定义;30Hz 下一帧 = 33ms,手感上等于立刻;
- **没有 session 时所有旧路径一字未改**(`lockstep == null` 时
  `recordCommand`/`update` 的分支与从前逐行相同);
- `reportHash` / `desyncTurn`:双方定期广播 `stateHash`,不一致就记下
  **最早**出问题的回合号——这是观战与回放判定"有人不同步/版本不同"
  的唯一证据,也是锁步自己修不了的那件事。

### `[v230]` 断言(9 条子断言,全部无头)

1. **到达顺序无关**:同一批命令按四种到达顺序 submit,`release()`
   出来的规范顺序**完全一致**(本轮最容易写错的一条);
2. **规范顺序 = 玩家 id 升序**;
3. **等慢机**:缺一个玩家的上报 → `ready()==false` 且 turn 不推进;
   补上立刻 ready;
4. **空回合也要心跳**:零命令的回合同样算上报;
5. **重复包不会执行两次**(同一玩家同回合第二次上报被忽略);
6. **线协议往返**:`encode`→`decode` 逐字段一致,含带逗号下标的复杂命令;
7. **坏行不抛异常**(与 `loadReplay` 同样的宽容);
8. **不同步可检出**且钉在**最早**出问题的回合;
9. **对战即回放**:一整场 session 的 `serialize()` 喂给 `loadReplay`,
   重放出的 `stateHash` 序列与联机时**逐点全等**(40 个采样点)。

### 真机复测清单(装 v2.30 后按顺序过)

1. **回归**:普通遭遇战 / 战役 / 回放三条老路径应与 v2.29 完全一致
   (本期的改动只在 `lockstep != null` 时生效,理论上零影响);
2. 存档→读档、暂停→重新开始、暂停→重播本局:三条重建路径都应正常;
3. 战役第 6 关之后仍可正常通关(锁步字段不该影响单人);
4. 下一批接上 `net/` 后,双机复测:
   - 两台同 WiFi 设备一台"主机"一台"加入",应进同一张图同一族;
   - 主机暂停时两台**同时**卡住(这是锁步的正常表现,不是死机);
   - 两边各自拉部队互推 3 分钟,终局判定应一致;
   - 中途一台开飞行模式 → 另一台应在同一帧卡住(等慢机),而不是
     继续跑;
   - 对战结束后导出的回放应能单独播放,且与联机时结果相同。
