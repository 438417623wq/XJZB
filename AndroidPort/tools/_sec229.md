## 八之二十九、v2.29:战役扩容(虫族五章 / 神族五章)

路线图最后一格「战役扩容」落地。`GameDesktop` 新增 `[v229]` 段 1 项
(15 个子断言),全量 **98 项 PASS**。十章是**纯数据**,不动任何模拟
代码——但为了把数据做对,顺手修掉了三个真 bug(见下)。

### 先探针(本轮铁律)

新增 `tools/_v229probe.py` / `_v229res.py` / `_v229zone.py`,先把
候选图的出生点、周围 32/64/128px 可行走率、每个出生点最近的矿簇

```

  → 出生点全部 100% 开阔,每点都有完整的 8 矿 + 1 气簇
```

### 探针挖出来的三个真 bug(全部已修)

1. **战役图没有任何矿区**。`Game.setMission` 会 `minerals.clear()`
   (对脚本化棋盘是对的:默认基地的矿点会压在任务单位下面),但它
   同时把**每一关**的矿脉清光了——探针实测 m01/m02/m05 的
   `minerals.size()==0`,`mineralsMined` 永远是 0。也就是说 m01 简报
   里那句「工人们会自己采矿」从来就是假的,而且**任何一关都无法
   造兵续命**(全关只有 400 起始晶体)。
   修法:任务 JSON 新增 `"economy": true` 开关,`setMission` 按它
   重新 `parseMapUnits(mapMeta)` 把该图真实的矿脉摆回来。五张老图里
   **m01/m04/m05 打开**(它们的简报确实承诺了采矿/矿区/人口),
   m02/m03 保持关闭(它们本来就是"用给你的兵打一场突击",文字里
   没有经济承诺,关掉反而更贴近设计)。

2. **`setMission` 不清默认基地的脚印**。默认开局在 `starts[0]`
   摆了 cc/barracks 并把占地写进了 `walk`;`ents.clear()` 只清实体
   不还地形,于是任务自己的单位如果正好站在"旧兵营"的位置,就被
   一圈**看不见的墙**围住。实测 m05 的 AI 四分钟产量在 27~38 之间
   乱跳,就是这个原因。修法:清实体的同时 `System.arraycopy(walk0,…)`
   把地形还原成原始位图。

3. **`GameView.restart()` 把任务整个丢掉**。战役里按"重新开始"会
   重建一个**裸遭遇战** `Game`——同一张图、对称开局、没有任务单位
   也没有目标,而且那一关从此**永远赢不了**。修法:把 missionJson
   存成字段,restart 时重新 parse + `setMission`,同时把
   `mapMeta` 补到 replay/load/restart 三条重建路径上(否则读档/
   回放/重开都拿不到经济)。

另外修掉一个**探针发现的旧数据错误**:`m05.json` 里两个虫族单位
(一个刺蛇、一个飞龙)站在 hunters 的悬崖里(3150,3180 与 3300,3200
是地图自带的两个 32px 坑),已挪到旁边可走格。同时给 `setMission`
加了一条通用兜底:任务里**机动单位**若被写在不可走的 minitile 上,
按 `nearestPassMini` 挪到最近可走格——和 `Mission.update` 对
延迟刷兵做的恢复完全一致;建筑不动(它本来就要贴格网)。

### 批次B:`[v229]` 断言(15 条子断言)

一个拼错的兵种 key 现在会**静默失败**(`setMission` 直接
`continue`,wave 事件静默跳过),所以这轮断言逐张扫
`missions/index.txt`:

1. 索引行与 JSON 的 id/map 一致,图在 `maps/index.txt` 里;
2. 两个 race 都是合法键;
3. **所有** `startUnits[].type`、`events[].units[]`、`aiWaves[][]`
   都在 `Game.TYPES` 里(本轮最有价值的一条);
4. 所有 `objectives[].kind` / `events[].action` 都是解析器认识的;
5. 每关有玩家主基地(cc/hatchery/nexus)且敌方有孵化场;
6. `protect` 的目标确实在开局棋盘上(否则第一帧就败);
7. 所有坐标在地图范围内;
8. 所有**建筑**站在可走地形上(`spawn` 只贴格网不查地形);
9. 建好之后,没有任何**机动单位**卡在地形里(问引擎,不问旁读);
10. `"economy": true` 的关卡真的拿回了矿脉。

### 未做(顺延)

- **敌营锚点仍是孵化场**:AI 的生产/集结/建造三处硬编码
  `hatchery`。要支持"人族敌军/神族敌军"需要把它抽成
  `aiTownHall()`(按 `aiRace` 返回 cc/hatchery/nexus)并按种族
  分叉 `aiPick` 的波次表。本期十章里的敌军**编制**已经可以用
  人/神单位(靠 `startUnits` 直接摆),但**增援与造兵**仍是虫族表;
- 不做章节选择 UI:任务表是顺序解锁的扁平数组,新增章节就是把
  列表接长,不需要新界面;
- 不做任务内过场对话(现有 briefing 文本够用);
- **老图 m01-m05 的难度是按"没有经济"平衡的**:给 m01/m04/m05
  打开矿脉后,这三关会明显**变简单**(玩家现在真的能造兵了)。
  这是修 bug 的必然结果,不是回归;真机复测时按新手体验重新确认,
  若嫌太软再单独调 `aiWaves`。
