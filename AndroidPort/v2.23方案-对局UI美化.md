> 前置状态:v2.22 已出包(91 项断言,能量池+隐形反隐+语音)。玩家反馈:
> 对局 UI"很怪,有多个半透明区域",要求**要么不透明要么全透明,半透明
> 一律不要**;拖动视野仍有大黑边;九宫格"大框里面一个小框"很乱。
> 原运输空投方案整体顺延为 v2.24(文档已改名,本文档插队)。
>
> 设计基调一句话:**面板是不透明的金属块,地图从面板之间的缝隙里露出来;
> 除此之外屏幕上没有任何一层"灰纱"。**

## 批次A:去半透明(整层删,不做"调淡")

1. **底台 scrim 删除**:CONSOLE_SCRIM 不再画,底台区域就是地图
   (v2.6 "缝隙是活战场"的立场走到头:面板浮在地图上,缝隙归地图);
2. **顶栏 scrim 删除**:资源/时间/战况数字改用 `drawOutlined` 描边字
   (现有函数,黑边+亮字,亮地形上可读性已验证),顶栏只剩一条 1px
   分隔线;暂停按钮面板保留(不透明金属);
3. **命令卡背板删除**(详见批次B 的整块面板替代方案,二选一,默认删);
4. **空选编队条背板删除**:三个编队槽改为各自独立的小不透明芯片;
5. Toast 提示条改**不透明**深底芯片(它常驻出现,也算对局 UI);
6. **保留**的半透明:暂停菜单/设置/任务简报/终局结算的整屏压暗——
   它们是模态层,按下暂停才出现,不属于对局常驻画面;
7. 自检清单:改完后全局 grep `argb(`,对局常驻路径(非模态)不允许
   再出现任何 alpha ∈ (0,255) 的整片填充;`[v224]` 断言加一条
   "常驻 UI 绘制调用序列中不存在半透明整片 fill"。

## 批次B:九宫格重绘(大框小框 → 一块面板)

1. **空选时命令卡整体隐藏**:没有选中单位就不画九宫格(现在空着也画
   一整块,是"框里框"的最大来源);编队 1/2/3 槽保留为三个小芯片;
2. **有选择时:一块不透明金属面板恰好包住 3×3**:
   - 面板 = `bevelPanel`(与暂停按钮/信息面板同一套金属词汇),
     外边距仅 2dp,不再是半格 pad 的大背板;
   - 格子间只画 1px 竖/横分隔线,**去掉每格自己的立体槽边**
     (现在每格有槽深+高光+描边三层线,叠上外框就是框中框);
   - 图标内边距 4dp→2dp,同尺寸下图标放大 ~15%;
   - 名称条保留(移动端要中文名),底色不透明深色、高度 12→10dp;
   - 价签/能量价签(能量格用蓝签,沿用 v2.22 规则)位置不变;
3. **命中判定零变化**:Btn 仍按 3×3 格矩形注册,S/M/L 缩放
   (v2.21 修复)原样保留——这次只动"画",不动"点";
4. 信息面板、小地图槽沿用现有不透明金属外观,形成一套统一语言:
   **深色金属底 + 亮边高光 + 1px 分隔**;
5. HudPreview 全量刷新,新增三态:`空选`(只有编队芯片)/
   `单选`(九宫格+信息面板)/`建造页`,并出一张
   `hud_transparency_audit.png` 标注全屏不再有半透明层;
6. `[v224]` 断言:空选时命令卡矩形为零、选中时面板恰含 3×3
   (面板宽 = 3×格+2×2dp)、图标 pad=2dp、常驻路径无半透明 fill。

## 批次C:拖动黑边根治(先诊断后三修)

1. **占位块提亮**(一行,收益最大):快速拖动时未解码 chunk 的
   小地图占位目前按原图画(:990),深色水域/阴影读成黑块——
   改用小地图同款 1.45× 提亮矩阵绘制,并叠 50% 透明度表示"加载中";
2. **预取圈 1→2、解码线程 2→3**:默认 zoom 1.3 下一屏约 2×2 块,
   外圈 2 环基本覆盖一次快速甩动的落点;解码池 2→3 线程,
   三块并发解码不至于排队(内存预算不变,chunkCap 仍 48);
3. **满屏兼容加固**:GameActivity 去掉 `FLAG_FULLSCREEN`
   (部分 ROM 见它就强制让位给刘海/导航),只留沉浸式 sticky +
   `SHORT_EDGES`;设置页"关于"加一行自检
   `屏幕: 满屏 / 被系统内缩 144px`——把 insets 打出来,真机一眼定位;
4. **回归**:真机四角四沿 + 快速甩动录屏;若仍有黑边,截图带
   自检行回来,按"内缩值"分流(cutout vs 占位块 vs 缝隙);
5. `[v224]` 断言:占位块走提亮管线、预取圈=2、Activity flags
   不含 FLAG_FULLSCREEN。

## 不做清单

- 不做面板自由换肤/主题色(等布局编辑器稳定后统一考虑);
- 不做底台重新变回整块不透明台面(v2.6 起的方向保留:面板浮在地图上);
- 模态菜单的压暗层保留,不算"半透明区域";
- 不动小地图/信息面板的布局几何(刚在 v2.19-2.21 定型)。
