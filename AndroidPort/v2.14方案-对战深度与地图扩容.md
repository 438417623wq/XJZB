## 二、v2.14 批次一:对战深度(P0,战斗手感的关键一轮)

### 1. 伤害类型 × 体型(克制三角形的骨架)

- `Type` 增加 `dmgType`(normal/explosive/concussive)与 `size`(small/
  medium/large);结算表按原版系数:**normal 1.0/1.0/1.0,
  explosive 1.0/0.75/0.5,concussive 1.0/0.5/0.25**(先扣类型系数再扣护甲)。
- 数据走查(手调,不依赖 dat):枪兵/小狗/狂热者 = small,
  喷火/刺蛇/龙骑 = medium,坦克/雷兽/雷兽/航母 = large;
 机枪/小狗/狂热者 concussive,坦克/瓦格雷/吞噬者 explosive,其余 normal。
- 命令卡与单位信息不展示类型(原版也不展示),但**平衡走查必须重跑**:
  桌面模拟"6 狗 vs 1 架塔坦克"应从"狗惨赢"变成"坦克清场"。

### 2. 溅射

- `Type.splashR`(半径)+ `splashFalloff`(边缘伤害比例);
- 接入点:炮弹类 `pendingShots` 落点结算处(坦克小溅射、攻城大溅射
  高伤、火焰兵短锥形、瓦格雷/吞噬者对空群伤)。
- 溅射**不分敌我**(原版规则)——自己的狗贴脸时坦克照样溅到,
  这正是"狗贴坦克"战术的来源,必须保留。

### 3. 驻守(Hold)

- `orderHold()`:原地停住,只对**武器射程内**的敌人自动开火,打完站回原点;
  被近战贴脸不还追(和 attack-move 的关键区别)。
- 命令卡补第 4 格(ic_hold 图标本来就有,把兴奋剂按钮换回自己的图标)。
- 桌面断言:驻守单位被远程打了会还手、被近战贴脸不移动、解除后可再下令。

### 4. 高地 miss(可选,时间允许再做)

- `pipeline_maps` 扩展:VF4 的海拔位(现行管线只取 bit0 可走性);
- 结算:低打高 **50% miss**(命中才结算,弹道照飞,表现原版的"打不中")。
- 若 VF4 海拔位不可靠,此项降级为"只做减速/不做",不硬凑。

### 5. 法术补全(第一批:素材已齐的五种)

| 法术 | 单位 | 素材 |
|---|---|---|
| EMP | 科学球 | `emp.grp` ✅ |
| 辐射 Irradiate | 科学球 | 生物持续掉血,绿色特效可程序化 |
| 大和炮 Yamato | 战巡 | `b_blastcan.grp`/`plasma.grp` ✅ |
| 锁定 Lockdown | 幽灵 | 目标停摆 8 秒(机械单位限定) |
| 干扰网 Disruption Web | 海盗船 | `dweb.grp` ✅(机制复用黑蜂:远程失效,不辨敌我) |

### 6. AI 一轮强化

- **防守反应**:己方建筑受击时,把最近兵营的集结兵拉回援防(现在只会
  硬冲玩家基地);
- **撤退**:波次兵力折损 > 60% 时回撤再攒(现在打到全灭);
- **会放法术**:templar 在敌密度 ≥3 时丢风暴、科学球对神族放 EMP、
  defiler 上黑蜂再冲锋;**且尊重机制**(不给黑蜂里的己方单位上风暴、
  不对隐身单位放非反隐法术——现在 AI 会犯这些错);
- **虫/神/人三族各自 build 顺序**(现在 AI 的建造逻辑仍偏虫族模板)。

### 验收(桌面断言,全部进 GameDesktop)

```
伤害类型: explosive 打 large = 原值、打 small = 50%;concussive 打 large = 25%
溅射: 架塔坦克一炮溅到相邻 2 狗;不分敌我(己方贴脸也掉血)
驻守: 被远程还手 / 被近战不动 / 打完回原点
法术: EMP 清盾、辐射持续掉血、锁定停摆机械、大和单发 260、
      干扰网内远程失效且不分敌我
AI: 受击回防;折损 60% 撤退;风暴不打黑蜂里的己方;三族 build 各自成型
回归: 既有 54 项断言不回退
```

    King of the Hill、StarCraft Fortress、Zergling Round-Up 等。

  沿用战役/遭遇战的页签框架);

  minimap 缩略与 LRU 瓦片缓存已有上限,但**256 图首次生成的构建时间**

### 2. 涂饰物渲染(第二次攻坚,素材/数据全在)

- 首选路径:**BWAPI / openbw 的 DoodadType 表**(社区已文档化 288 个

- 备选:高频 id 人工钉死(每瓦片集 TOP10≈40 个 id 覆盖 80% 摆放),
  用 dddata.bin 512 字节记录的放置多边形尺寸做交叉验证;
- 渲染规则:涂饰物画在地形之上、单位之下;**大涂饰物标记不可走**
  (写回 walk 图,避免单位穿树);按 `doodad=` 行惰性加载;
- 验收:Lost Temple/Blood Bath 与原版截图并排对照,树/岩石落点一致;
  桌面渲染帧肉眼验收 + 涂饰物不堵出生点/矿点。
