# v2.42 方案:滑动黑条根治 + 信息面板瘦身 + 编队独立部件

> 前置状态:v2.41 已出包(六部件 HUD、战场全屏)。真机反馈三条:
> ① 快速滑动视野出现横贯黑条,有割裂感(玩家补充:**快速滑动才出现**,停放不出现);
> ② 底部信息面板太大、展示内容太多;③ 编队要做成独立 UI。
> 本文按铁律「先证据后代码」对两张真机截图(2608×1200)做了逐像素配准取证,
> 黑条实为**两个独立缺陷**:一个已 100% 定案(资产),一个已收窄到唯一管线(瞬态)。

---

## 一、取证结论(全部可复现,脚本在 tools/)

对截图做了模板配准:16 块 chunk 拼成世界画布,与截图特征区相关匹配,解出
**camX=1032、camY=634、zoom≈1.33**(divide,64×64 tile,MTXM 逐 tile 核对)。

### 缺陷A:黑块(永久,世界固定)——已定案

| 证据 | 数据 |
|---|---|
| 截图黑块 | 屏幕 (2389-2512, 701-741),纯黑(0,0,0),无纹理 |
| 反推世界坐标 | (1848-1940, 710-740) = **tile 列 58-60、行 22(3×1 tile)** |
| divide MTXM | `MTXM[22][58..60] = 0x0000`(全图仅此 3 个虚空 tile) |
| 渲染链 | 0x0000 → grp=0/var=0 → **megatile 0 → 1024 像素全为 (0,0,0)**(实测) |
| 小地图 | minimap.webp 同区域有烤入黑短线(小地图由 chunk 缩放生成,同一来源) |
| 烘焙工具 | `pipeline_maps.py:380` `Image.new("RGB",…)` 黑底;`drawn` 循环忠实画出 megatile 0 的黑色像素 |

**结论:原版地图的「虚空 tile」(0x0000)被烘焙管线画成纯黑。** 原作里这类
区域在可玩区之外,本作相机钳制到全图矩形,玩家平移过去就看到黑块。
小地图上的黑线是同一来源,不是渲染 bug。

### 缺陷B:黑条(瞬态,快速滑动出现)——已收窄到 chunk 渲染管线

形态(截图逐行测量):两条**全宽纯黑带**,屏幕 y≈414-450 与 1101-1140,
**间距 ≈ 512×zoom = chunk 行距**;每条带在屏幕 x≈1310(世界 x≈1024±8,
即 chunk 列边界)处**上下错位约半格(≈16 世界px)**;带内无纹理、边缘锐利。

排除清单(全部验证过,不是猜):

| # | 假设 | 排除依据 |
|---|---|---|
| 1 | chunk 资产有黑边/黑行 | APK 内 16 块 chunk 顶/底 16 行逐像素扫描:干净 |
| 2 | 雾(fog=0/1 行) | 小地图叠同一张雾图,对应行均值 90-100(全亮);且 HOK 模式雾全透明 |
| 3 | 虚空 tile 成行 | 全图仅 3 个 0x0000(见缺陷A) |
| 4 | HUD/显式全宽填充 | render→drawHud 全链 grep:`drawRect(0,0,W,H)` 仅 5 处,全在模态层 |
| 5 | 共享 Paint 状态残留 | `p` 无任何 setColorFilter/setXfermode/setShader |
| 6 | 占位符放大暗行 | minimap 全行/半宽行扫描无 <30 暗行 |
| 7 | 世界固定层 | 第二张截图(含同一边界 512 在视野内)同位置完全干净 |

**结论:黑条只出现在快速滑动这一运动状态,锁定在地形 chunk 绘制管线的瞬态行为
(解码未完成/LRU 驱逐/占位符/光栅化缝隙家族)。静态分析已到极限,按铁律下一步
是真机插桩取证,而不是猜一层改一层。** v2.21/v2.24 修的是同一家族的另外两种形态
(cutout、钳制、1px 缝、占位发黑),本次是第四种形态。

### 底部信息面板与编队现状(行号)

## 二、批次A:资产黑块根治(半天)

1. **void tile 替代渲染**(`pipeline_maps.py` build_map):MTXM 0x0000(判定:
   `raw == 0`)不再画 megatile 0,改为「邻近地表延拓」——优先取同一 chunk 内
   左侧最近的非零 tile 的 megatile,整行皆无则取上方;无任何邻居(全零图)时
   用 tileset 默认地表 megatile。**只改渲染,walk/elev 照旧从原 MTXM 生成**
   (虚空区本就不可走,数值不变);
2. **全图重扫**:153 图 census 后只重烘焙含 0x0000 的图(divide 确认 3 个;
   其余图由 census 给出清单);`slim_assets.py` 照常走 webp;
3. **小地图自动修复**(它由 chunk 缩放生成,无需单独处理);
4. `[v242]` 资产断言(GameDesktop):对所有 `maps/*/c_*.webp + minimap.webp`
   解码扫描,**纯黑连通块 ≥8×8 = 0**。

## 三、批次B:瞬态黑条——插桩诊断 + 三道加固(一天)

1. **诊断开关**(设置页新增「渲染诊断」,默认关):
   - 开启后:每个可见 chunk 的 dst 画 1px 描边(行/列奇偶两色);占位符整块
     染品红;每 30 帧限频输出一行日志(visible hit/miss 数、zoom、camX/camY);
   - 黑条再现时截一张图即可判定:带在**块内**(位图内容问题)/**块间**(dst
     覆盖问题)/**覆盖在一切之上**(叠加层问题)——三种结论对应三种修法;
2. **同包加固**(各自消灭一类假设,真机 A/B):
   - a. 占位符去黑化:veil alpha 128→96,并保证 patch 输出均值不低于地表均色
     (「加载中」可以有,「黑」不可以有);
   - b. 缝隙家族整体消灭:chunk 绘制 paint 加 `FILTER_BITMAP_FLAG`(双线性),
     右/下溢出 1px→4px,`sx/sy` 的 dst 取整统一为 floor;
   - c. 可见块不驱逐:`chunkCap` 生效时跳过对当前可见 key 的驱逐(LRU touch),
     消灭「ring 预取把可见块挤出缓存→再解码」的循环(24-cap 小内存机型尤其);
3. `[v242]` 断言:任取 200 组 (camX,camY,zoom) 扫描,chunk dst 联合覆盖无洞;
   占位符输出亮度有下限;cap ≥ 可见数+ring 数。

## 四、批次C:信息面板瘦身 + 编队独立部件(一天)

1. **编队升为第七部件**:
   - `HudLayout` 新增 `P_GROUPS`(idx 5),`SPEC_LEN` 15→18,输出
     `groups` 矩形;默认摆位:信息面板左侧竖排 2×5(宽 5 格、高 2 格,
     格 26dp),镜像预设靠右,紧凑预设挂命令卡上方;
   - 绘制:统一走 `drawFormationOnly` 的芯片画法,画到 `hud.groups`;
     **删除** `drawSelInfo` 里的嵌板编队格(3043-3066),空选/有选择画同一处;
   - `inHud()`/命中:加入 groups 矩形;`formationRect` 退役;
   - 布局编辑器 5→6 面板,旧 15-float 存档迁移(新面板落默认位);
2. **信息面板瘦身**:
   - `hud.middle` 不再拉伸到 H-8dp:**高度跟随内容**(默认预设单选 ≈72dp,
     是现在 156dp 的一半),顶部仍与小地图顶对齐;
   - 单选内容一行化:头像 48dp + 右侧「名称 + 血条」同列;**删英文副标题**
     (与中文名重复);攻击/射程并成一行 9dp 小字;
   - 多选:兵种格压到一行 40dp,数量角标保留;
   - 编队格移出后,面板宽度按内容收缩(单选不再撑满到命令卡);
3. HudPreview 全量刷新:七部件三态(空选/单选/多选)+ 编辑器六面板图。

## 不做清单

- 不做部件换肤/主题色;不做面板透明度可调;
- 不动联机/锁步代码;不改雾模式语义(SC/王者保持现状);
- 不做 void 区域相机禁入(批次A 改地表后无需禁入);
- 不在本人机猜测层面直接改黑条的绘制代码——先插桩定层再修(铁律)。

## 执行顺序与门禁

```
批次A(资产,独立可先行)→ 批次B(诊断+加固)→ 批次C(部件)
——三批同包发版;A 是烘焙产物,B 是渲染管线,C 是布局与绘制,互不耦合
门禁 = GameDesktop 全绿([v242] 资产断言 + 覆盖断言 + 部件断言)
     → HudPreview 七部件三态刷新
     → APK 素材比对:仅重烘焙地图的 chunk/minimap 变更,其余 diff=0
     → 真机:
       1. divide 东缘 (58-60,22) 黑块消失,小地图同位黑线消失;
       2. 快速全屏甩动 ×10(四角四沿、来回甩)无黑条;若再现,
          开「渲染诊断」截一张图回传(色框可直接读出黑条在哪一层);
       3. 信息面板高度约为原来一半,单选无英文副标题、内容不溢出;
       4. 编队 1-10 在空选/有选择/布局编辑三种状态下位置一致、可点、可长按指派;
       5. 布局编辑器六面板拖拽、S/M/L、保存重载正常,旧自定义布局迁移不丢。
```

铁律不变:**先证据后代码、GameDesktop 断言逐条加(本轮 `[v242]`)、
HudPreview 全分辨率刷新、APK 素材比对、每批真机过一遍并记录。**
